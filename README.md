# BaiMai (ใบไม้) 🍃
### “อารมณ์คือใบไม้ ที่สักวันจะร่วงหล่น”
> เว็บแอปพลิเคชันเพื่อสุขภาวะทางใจ พื้นที่ปลอดภัยสำหรับปล่อยวางความรู้สึก และระบบคัดกรองดูแลสุขภาพใจนิสิต มหาวิทยาลัยมหาสารคาม (MSU)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **🍃 ปล่อยความรู้สึก (Venting Space - Zero-Data Retention)**
   - พื้นที่เขียนระบายความรู้สึกในใจแบบส่วนตัว 100%
   - Signature Animation: กระดาษแยกส่วนและสลายกลายเป็น **ใบไม้ร่วงหล่นและปลิวสลายไปตามสายลม** (Falling & Swirling Leaves)
   - ไม่มีการจัดเก็บข้อความระบายลงฐานข้อมูล สลายหายไปทันทีหลังกดปล่อย

2. **🧠 แบบประเมินสุขภาพใจ (อิงเกณฑ์มาตรฐาน กรมสุขภาพจิต)**
   - **2Q**: แบบคัดกรองโรคซึมเศร้าเบื้องต้น 2 คำถาม
   - **9Q**: แบบประเมินภาวะซึมเศร้า 9 คำถาม พร้อมเกณฑ์แปลผลและการนัดหมายติดตามอาการ
   - **8Q**: แบบสำรวจความปลอดภัยและดูแลใจตนเอง (ไม่ทำร้ายตัวเอง) หลีกเลี่ยงคำว่า "ฆ่าตัวตาย" เพื่อความอ่อนโยนต่อผู้ใช้งาน

3. **🏛️ ระบบดูแลนิสิต มหาวิทยาลัยมหาสารคาม (MSU Care Sync)**
   - ทางเลือกตัดสินใจของผู้ใช้งาน (Informed Consent): นิสิตสามารถเลือกที่จะซิงก์ข้อมูลหรือรักษาความเป็นส่วนตัวสูงสุดได้ด้วยตนเอง
   - เชื่อมโยงช่องทางติดต่อของ **ศูนย์สุขภาวะนิสิต กองกิจการนิสิต มมส.** (043-754388) และ **โรงพยาบาลสุทธาเวช คณะแพทยศาสตร์ มมส.** (043-021-021)
   - ออกรหัสเคสติดตามอาการ (`MSU-CARE-XXXX`)

4. **🔒 พอร์ทัลอาจารย์และผู้ให้คำปรึกษา มมส. (`/counselor`)**
   - **Passcode Authentication Gate**: ป้องกันการเข้าถึงด้วยระบบรหัสผ่านเจ้าหน้าที่ มมส. (รหัสผ่านเริ่มต้นทดสอบ: `msu2026`)
   - ปกป้อง API ด้วย Token Authorization Header (`x-counselor-auth`) ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
   - แดชบอร์ดสรุปสถิติ, ค้นหาตามรหัสนิสิต/คณะ/เคส, ปรับสถานะการดูแล และสมุดบันทึกโน้ตติดตามอาการ

5. **🌬️ ผ่อนคลาย & ฝึกหายใจ (`/breathe`)**
   - กิจกรรมฝึกหายใจ 2 โหมด: Box Breathing (4-4-4-4) และ 4-7-8 Deep Calm พร้อมวงกลมขยาย-หดและเสียงบำบัด

6. **😊 เช็กอารมณ์ประจำวัน (`/mood`)**
   - สังเกตอารมณ์ 5 ระดับ พร้อมเก็บบันทึกประวัติบนเบราว์เซอร์ส่วนบุคคล

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4, Custom Pastel Palette, Paper Texture
- **Animation**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Audio Synthesis**: Web Audio API (Chime 528 Hz, Paper Tear)
- **Backend / API**: Next.js Route Handlers, Local Persistence / Supabase Ready

---

## 🚀 การติดตั้งและรันโปรเจกต์

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันโหมด Development
npm run dev

# 3. Build สำหรับ Production
npm run build
```

เปิดบราวเซอร์ที่ [http://localhost:3000](http://localhost:3000)

## 🛡️ นโยบายความเป็นส่วนตัว (PDPA Compliance)
ข้อมูลข้อความระบายความรู้สึกในฟังก์ชัน "ปล่อยความรู้สึก" จะทำงานเฉพาะบนหน่วยความจำชั่วคราวของเบราว์เซอร์ (Client-side memory) และถูกทำลายทิ้งทันที 100% ไม่มีการบันทึกหรือดักจับข้อมูลใด ๆ ข้อมูลแบบประเมินจะถูกจัดเก็บเฉพาะเมื่อนิสิตให้ความยินยอมโดยชัดแจ้งเพื่อการดูแลสุขภาวะต่อเนื่องเท่านั้น
