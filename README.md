# BaiMai (ใบไม้) 🍃
### “อารมณ์คือใบไม้ ที่สักวันจะร่วงหล่น”
> เว็บแอปพลิเคชันเพื่อสุขภาวะทางใจ พื้นที่ปลอดภัยสำหรับน้อง ๆ มัธยมต้นในการปล่อยวางความรู้สึก และระบบดูแลสุขภาพใจโดยพี่ ๆ ผู้ดูแล BaiMai Care

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **🍃 ปล่อยความรู้สึก (Venting Space - Zero-Data Retention)**
   - พื้นที่เขียนระบายความรู้สึกในใจแบบส่วนตัว 100%
   - Signature Animation: กระดาษแยกส่วนและสลายกลายเป็น **ใบไม้ร่วงหล่นและปลิวสลายไปตามสายลม** (Falling & Swirling Leaves)
   - ไม่มีการจัดเก็บข้อความระบายลงฐานข้อมูล สลายหายไปทันทีหลังกดปล่อย

2. **🧠 แบบประเมินสุขภาพใจ (อิงเกณฑ์มาตรฐาน กรมสุขภาพจิต)**
   - **2Q**: แบบคัดกรองความเหนื่อยล้าทางใจเบื้องต้น 2 คำถาม
   - **9Q**: แบบประเมินภาวะซึมเศร้า 9 คำถาม พร้อมเกณฑ์แปลผลและการดูแลใจที่นุ่มนวล
   - **8Q**: แบบสำรวจความปลอดภัยและดูแลใจตนเอง (ไม่ทำร้ายตัวเอง) ปรับภาษาเป็นกันเอง อ่อนโยน และหลีกเลี่ยงคำว่า "ฆ่าตัวตาย" 100%

3. **🌱 ระบบดูแลน้อง ๆ (BaiMai Care Sync)**
   - ทางเลือกตัดสินใจของน้อง ๆ (Informed Consent): น้อง ๆ สามารถเลือกซิงก์ข้อมูลเพื่อให้พี่ ๆ ผู้ดูแลติดต่อกลับ หรือรักษาความเป็นส่วนตัวสูงสุดได้ด้วยตนเอง
   - เชื่อมโยงช่องทางดูแลช่วยเหลือ เช่น สายด่วนสุขภาพวัยรุ่นและเยาวชน Lovecare (1663) และสายด่วนสุขภาพจิต (1323)
   - ออกรหัสเคสดูแลใจ (`BAIMAI-CARE-XXXX`)

4. **🔒 พอร์ทัลพี่ ๆ ผู้ดูแล (`/counselor`)**
   - **Passcode Authentication Gate**: ป้องกันการเข้าถึงด้วยระบบรหัสผ่านพี่ ๆ ผู้ดูแล (รหัสผ่านเริ่มต้น: `baimai2026` หรือ `baimai`)
   - ปกป้อง API ด้วย Token Authorization Header (`x-counselor-auth`) ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
   - แดชบอร์ดสรุปสถิติดูแลน้อง ๆ, ค้นหาตามชื่อ/ระดับชั้น (ม.1-ม.3)/โรงเรียน/เลขเคส, ปรับสถานะการดูแล และสมุดบันทึกโน้ตติดตามอาการ

5. **🌬️ ผ่อนคลาย & ฝึกหายใจ (`/breathe`)**
   - กิจกรรมฝึกหายใจ 2 โหมด: Box Breathing (4-4-4-4) และ 4-7-8 Deep Calm พร้อมวงกลมขยาย-หดและเสียงคลื่นความถี่บำบัด 528 Hz

6. **😊 เช็กอารมณ์ประจำวัน (`/mood`)**
   - สังเกตอารมณ์ 5 ระดับ พร้อมเก็บบันทึกประวัติบนเบราว์เซอร์ส่วนบุคคล

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4, Custom Pastel Palette, Paper Texture
- **Animation**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Audio Synthesis**: Web Audio API (Chime 528 Hz, Paper Tear)
- **Backend / API**: Next.js Route Handlers, Local Persistence / Supabase Ready

```bash

# 2. รันโหมด Development
npm run dev

# 3. Build สำหรับ Production
```

## 🛡️ นโยบายความเป็นส่วนตัว (PDPA Compliance)
ข้อมูลข้อความระบายความรู้สึกในฟังก์ชัน "ปล่อยความรู้สึก" จะทำงานเฉพาะบนหน่วยความจำชั่วคราวของเบราว์เซอร์ (Client-side memory) และถูกทำลายทิ้งทันที 100% ไม่มีการบันทึกหรือดักจับข้อมูลใด ๆ ข้อมูลแบบประเมินจะถูกจัดเก็บเฉพาะเมื่อน้อง ๆ ให้ความยินยอมโดยชัดแจ้งเพื่อให้พี่ ๆ ผู้ดูแลติดต่อกลับและดูแลสุขภาพใจต่อเนื่องเท่านั้น
